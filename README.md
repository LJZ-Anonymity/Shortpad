## 项目简介

Shortpad 是一个基于 WPF（.NET 8）开发的 Windows 桌面工具。通过键鼠快捷键呼出一个按钮面板，每个按钮可以绑定一个动作，例如打开程序、文件或文件夹、运行程序，或运行扩展程序。

本项目是独立开发的学习项目，交互思路参考了 Quicker 这类快捷操作工具。

---

## 功能

- 键鼠快捷键呼出面板
- 按钮可绑定动作：打开程序、文件、文件夹、网页，运行程序，运行扩展程序
- 窗口句柄拾取，用于加入黑名单或绑定窗口所在进程
- 全局、通用、任务栏、桌面等场景管理
